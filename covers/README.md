# Обложки: как заставить нейросеть написать по-русски

Нейросети рисуют приличные обложки — пока не попросишь написать на них
кириллицей. Ломается предсказуемо, по одним и тем же местам.

## Три места, где кириллица рассыпается

Реальные примеры из моих генераций:

| Просил | Получил | Что произошло |
|---|---|---|
| ПОЛОВИНА | ПОЛОВ**Й**НА | буква И получила краткую |
| НАПРОКАТ | НА**ПИ**РОК**У**Т | подмена и вставка в длинном слове |
| ИИ-АВАТАР | РФИ-РЂАВУТРАЙ | дефис внутри слова убил слово целиком |
| ПАМЯТЬ | ПАМЯТ**ЬЬ** | удвоение последней буквы |

## Что лечит — три приёма сразу

Поодиночке не помогает ни один, нужны все три в одном промпте:

1. **Общая шапка** перед блоками текста: всё написание — кириллица, рендерить
   только перечисленные символы, в перечисленном порядке, ничего не вставляя и
   не подменяя, и перед завершением сверить каждое слово по буквам.
2. **Побуквенная запись с позициями**: не «слово ПАМЯТЬ», а «шесть символов:
   П, А, М, Я, Т, Ь; позиция 1 — П, позиция 2 — А… слово заканчивается на
   позиции 6, после неё ничего нет».
3. **Негативное указание** по буквам, которые модель любит подставлять:
   «в этой строке нет И и нет Й», «ровно один мягкий знак, удвоения нет».

Со второй попытки обычно встаёт чисто. Одна генерация — около 12 рублей, так что
перегенерить дешевле, чем возиться.

⚠️ **Читать результат глазами обязательно.** Весь брак — текстовый, и никак иначе,
кроме как посмотрев на картинку и вычитав слова по буквам, он не ловится.

## Почему обложка выходит «пустой»

Отдельная беда, не связанная с текстом. Пять причин, все проверены на
забракованных вариантах:

1. **Нет человека в кадре.** Даже когда тема про отсутствие человека — лицо
   прячем, героя оставляем. Запрет `no people` даёт мёртвый натюрморт.
2. **Сцена не в полный вылет.** Писать явно: `FULL BLEED, edge to edge, no empty
   margin`.
3. **Задний план не заказан предметно.** Перечислить: полка с книгами, растение,
   лампа, свет из окна, мягкая расфокусировка.
4. **Заголовок в две строки вместо трёх.** Две строки мелким кеглем не держат
   плакатную плотность.
5. **Красный круг вокруг крупного объекта.** Он должен быть тугим и вокруг
   мелкой смысловой детали.

## Что здесь лежит

| Файл | Что это |
|---|---|
| [`prompt-template.md`](prompt-template.md) | Полный шаблон промпта с разметкой под подстановку |
| [`stopper_overlay.py`](stopper_overlay.py) | Запасной путь: накладывает панель и текст поверх готового арта через Pillow |

Запасной путь нужен, если кириллица не встала за две попытки. Тогда просим у
модели арт **без единой буквы**, а текст ставим сами — шрифтами, которые заведомо
умеют в кириллицу. Параметры (путь к арту, текст, какое слово красным) — в начале
скрипта.

```bash
pip install pillow
python stopper_overlay.py
```
