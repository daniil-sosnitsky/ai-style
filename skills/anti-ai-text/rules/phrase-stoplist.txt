# Личный стоп-лист сожжённых фраз.
#
# Стартует пустым, и это правильно: сюда попадают не «плохие фразы вообще», а
# ТВОИ формулировки, которые повторились в двух и более готовых текстах.
# Увидел клон своей же фразы - строка в этот файл. Через месяц здесь будет
# список того, чем ты сам себя выдаёшь.
#
# Как подключить:
#     python scripts/check_text.py текст.md --stoplist rules/phrase-stoplist.txt
#
# Одна строка - одна фраза. Регистр не важен. Строки с # не считаются.
# Звёздочка на конце означает основу слова: «разберём*» поймает и
# «разберёмся», и «разберёмте».
#
# Примеры того, что сюда попадает (у меня попало именно это -
# шесть вариантов одной и той же подводки к списку):
#

# Коротко, если нет времени на всю статью:
