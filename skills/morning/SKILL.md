# /morning — начало дня

Тонкий оркестратор. Собирает 4 моста в один результат: дневная заметка +
Telegram-пост. Сам логику мостов не дублирует — читает их из `bridges/`.

## Перед стартом
Прочитай конфиг и контракт:
- `daily-common/paths.md` — пути и ID.
- `daily-common/contract.md` — формат вывода.
- `daily-common/templates.md` — шаблоны.

Аргумент: `/morning` — все мосты; `/morning finance` (или work/personal/sport) —
только один мост, без сборки поста.

## Процесс

1. **Дата и заметка.** Определи сегодняшнюю дату. Если `daily/ГГГГ-ММ-ДД.md`
   нет — создай из шаблона. Если есть (перезапуск) — не затирай, дополняй.

2. **Прогон мостов.** Для каждой сферы прочитай `bridges/<мост>.md` и выполни.
   Каждый мост вернёт `daily_block`, `telegram_block`, `writes` (см. contract).
   Мосты:
   - `bridges/work.md` — Работа (задачи + развитие + соцсети, вчерашние сессии)
   - `bridges/personal.md` — Личная жизнь
   - `bridges/finance.md` — Финансы (+ эфемерная новость)
   - `bridges/sport.md` — Спорт

3. **Приоритизация и фокус.** По всем задачам дня выбери **один фокус дня**
   по правилу из contract.md (просрочка → дата → баланс сфер → окна фокуса).

4. **Устье и подтверждение.** Покажи в терминале: фокус (с обоснованием) + 4
   секции. Спроси подтверждение/правку фокуса. Дождись «ок». Это твоё
   решение — ИИ не ставит фокус молча.

5. **Запись.** После «ок»:
   - Собери дневную заметку по шаблону, запиши в `daily/ГГГГ-ММ-ДД.md`.
   - Долговечное разложи по профильным папкам.
   - Собери Telegram-пост по шаблону в файл и отправь через `send_telegram.py`.
   - **Новость дня в заметку НЕ сохраняй** — только в пост.

## Тон
На «ты», по-деловому, живо. Обоснование фокуса — конкретное, без воды.
Эмодзи — умеренно, для акцентов.
