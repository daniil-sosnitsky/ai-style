# /morning — утренний планировщик дня (скилл для Claude Code)

Это очищенная, обезличенная версия моего личного скилла `/morning`. Он
запускает рабочий день: собирает задачи из 4 сфер (Работа, Личное, Финансы,
Спорт), выбирает **один фокус дня** с обоснованием, пишет заметку дня в
ваш волт Obsidian и отправляет утренний пост в Telegram.

> Канал, где я показываю, как собираю такие системы: https://t.me/ai_style

## Архитектура

- `SKILL.md` — тонкий оркестратор. Сам логику не дублирует — читает мосты.
- `bridges/` — по одному файлу на сферу (work / personal / finance / sport).
- `daily-common/` — общий конфиг: пути/ID (`paths.md`), контракт вывода
  мостов (`contract.md`), шаблоны (`templates.md`).
- `send_telegram.py` — простой отправщик поста в Telegram (токен из `.env`).

## Как адаптировать под себя

1. Положи папку `morning/` в свои скилы Claude Code (`~/.claude/skills/`).
2. В `daily-common/paths.md` замени все `<ПЛЕЙСХОЛДЕРЫ>` на свои пути и ID.
3. Создай `.env` для Telegram-бота (см. `.env.example`) — токен и chat_id.
   Секреты только в `.env`, никогда в коде и не в гите.
4. Настрой свою базу задач (я использую Notion) — или замени источник задач
   в мостах на свой (таблица, файл, другой таск-менеджер).

Финансовый мост у меня тянет статус торговых ботов с моего сервера — это
опционально и вырезано; оставь только то, что нужно тебе.
