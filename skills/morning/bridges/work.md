# Мост «Работа» 🧩

Сфера включает: рабочие задачи, личное развитие и обучение, **ведение соцсетей**.

## Источники
- База задач (у меня Notion): задачи сферы Работа на сегодня (view
  «📌 Сегодня») + просроченные хвосты (view «🔥 Хвосты»). Классификация —
  по contract.md.
- Вчерашние сессии Claude Code (`~/.claude/projects/*/*.jsonl`): **кратко** —
  какие проекты трогал вчера и что осталось незакрытым. Не разбирай
  каждую сессию, только проекты + хвосты.
- `profile/working-style.md`, `profile/strengths.md` — окна фокуса, как
  навигировать, а не мотивировать; дробить на видимые победы.
- `content/` — контент-план соцсетей: что запланировано.

## Что произвести
- `daily_block`: задачи Работы на сегодня (с приоритетом по contract), хвосты
  вчерашних сессий, контент-план дня. Подсказки по задачам.
- `telegram_block`: 3–5 главных пунктов Работы одной колонкой.
- `writes`: если по ходу дня появились рабочие заметки/контент — предложить
  запись в `content/`; статусы задач утром не трогаем (это вечерний /evening).

## Заметки
- Соцсети — полноценная часть Работы: если сегодня есть план публикации,
  вынеси его явно и предложи черновик в `content/`.
- Развитие (чтение, вебинары, обучение) тоже сюда.
