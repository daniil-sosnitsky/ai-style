# Скилы для Claude Code

Публичные версии скилов, которые работают у меня каждый день. Личные данные, токены
и ключи вырезаны: пути и ID заменены плейсхолдерами, секреты подключаются через `.env`.

| Скилл | Что делает | Что нужно |
|---|---|---|
| [`anti-ai-text/`](anti-ai-text/) | **Проверка текста на нейросетевой почерк.** Скрипт показывает с номерами строк, где тире и кликбейт, какая плотность штампов, насколько ровный ритм абзацев. Внутри разбор следов по трём уровням и шаблон личного стоп-листа фраз | Python 3.9+ |
| [`token-budget/`](token-budget/) | **Система экономии токенов.** Три отчёта по своим сессиям (куда уходит бюджет, сколько стоит вход в сессию, в какой момент разговор стал дорогим), четыре помощника на дешёвых моделях, правила для `CLAUDE.md` и проверка, что экономия настоящая | Python 3.9+ |
| [`topic-radar/`](topic-radar/) | **Система поиска тем.** Держит карту написанного, ловит дубли по паре «объект + угол», считает спрос и скорит кандидатов по 8 критериям. Внутри процедура калибровки — как вывести свои веса и свои отсечки по цифрам своего канала | — |
| [`morning/`](morning/) | **Утренний планировщик.** Собирает задачи из четырёх сфер, выбирает один фокус дня с обоснованием, пишет заметку дня и отправляет пост в Telegram | Python 3.9+, Obsidian, бот Telegram |

## Как устроен каждый скилл

| Файл | Для кого |
|---|---|
| `README.md` | Для тебя: что делает, как поставить, чего не делает |
| `SKILL.md` | Для агента: инструкция, которую он читает сам |
| остальное | Скрипты, шаблоны, вспомогательные файлы скилла |

Куда класть: папку скилла целиком в `~/.claude/skills/`. Дальше читай его `README.md` —
в каждом есть раздел **«Как поставить себе»** с пошаговой настройкой.
