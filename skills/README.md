# Skills

Публичные, очищенные от секретов версии моих скилов для Claude Code.

Каждый скилл лежит в своей подпапке с инструкцией «как повторить». Личные данные,
токены и ключи вырезаны — в реальной работе они подключаются через переменные
окружения (`.env`), а не хранятся в коде.

| Скилл | Что делает |
|---|---|
| [`morning/`](morning/) | Утренний ассистент: собирает задачи из четырёх сфер, выбирает один фокус дня с обоснованием, пишет заметку и отправляет пост в Telegram |
| [`topic-radar/`](topic-radar/) | Система поиска тем: держит карту написанного, ловит дубли по паре «объект + угол», считает спрос и скорит кандидатов по 8 критериям. Веса посчитаны по 34 статьям и 280 тысячам показов |
