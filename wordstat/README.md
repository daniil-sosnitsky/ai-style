# Проверка спроса по Вордстату

Скрипт прогоняет список тем через Яндекс Вордстат и возвращает частотность —
сколько раз за месяц люди вбивали фразу в поиск. Нужен, когда тем не одна-две,
а полсотни, и вбивать руками каждую превращается в рутину.

## Зачем это

Разброс между темами, которые на глаз выглядят одинаково перспективными, доходит
до четырёх порядков. Реальные цифры из моего списка:

| Тема | Показов в месяц |
|---|--:|
| claude code | 67 147 |
| ии планировщик задач | 90 |
| ии агент своими руками | 24 |
| нейросеть планирует день | 4 |

Все четыре темы были мне одинаково интересны. Разница — в пятнадцать тысяч раз.

## Главная ловушка

**Высокая частотность не равна хорошей теме.** Частотность не знает интента — того,
что человек хочет получить. Запрос «нейросети» соберёт десятки тысяч показов и
приведёт всех подряд: новости, документацию, курсовую студенту.

Узкая цифра с точным интентом почти всегда ценнее широкой с размытым. И наоборот:
низкая цифра не значит «не пиши» — она значит «тема маленькая», и лучше знать это
заранее, чем постфактум по нулевым охватам.

## Установка

```bash
pip install requests
cp .env.example .env   # и заполнить своими ключами
```

Нужен сервисный аккаунт в Yandex Cloud с ролью `search-api.webSearch.user`:
API-ключ и идентификатор каталога кладутся в `.env`.

## Запуск

```bash
python wordstat.py --file phrases.txt      # список фраз, по одной на строку
python wordstat.py "память нейросети"      # одна фраза
```

Результат складывается в `exports/`, ответы API кэшируются в `cache/` — повторный
прогон того же списка бесплатный.

## Что нужно знать про API

- Старый API Вордстата с входом через OAuth закрыт. Актуальный — **Yandex Cloud
  Search API v2**.
- Стоимость: 20 ₽ за 1000 запросов частотности и динамики, 50 ₽ за 1000 запросов
  региональной статистики. Справочник регионов бесплатный.
- Лимиты: 10 запросов в секунду, 100 в час. Массовую проверку планируй заранее.
- ⚠️ **Операторы из браузерной версии в API не работают.** Кавычки `"фраза"`,
  фиксация формы `!слово`, минус-слова `-слово` действуют только на
  wordstat.yandex.ru. Через API частотность приходит по более общей формуле, и
  числа будут выше — сравнивай только с числами из того же источника.

## Если тема одна

Никакой скрипт не нужен: открой wordstat.yandex.ru и вбей фразу руками. Операторы
там работают, и это бесплатно.
