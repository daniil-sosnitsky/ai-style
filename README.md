# ai-style

Открытые материалы канала «AI-стиль жизни» ([@ai_styledanila](https://t.me/ai_styledanila)):
скилы для Claude Code, скрипты и разборы. Собираю AI-системы сам, поверх основной
работы, и показываю, как повторить.

Всё здесь работает у меня каждый день. Публичные версии — те же, только без личных
данных: пути и ID заменены плейсхолдерами, секреты вынесены в `.env`.

## Скилы для Claude Code

Ставятся в `~/.claude/skills/`, запускаются командой в сессии. Внутри каждой папки —
`README.md` («что делает и как поставить») и `SKILL.md` (инструкция для агента).

| Скилл | Что делает | Что нужно |
|---|---|---|
| [`skills/token-budget/`](skills/token-budget/) | **Система экономии токенов.** Показывает, куда уходит бюджет, сколько стоит вход в сессию и в какой момент разговор стал дорогим. Плюс четыре помощника на дешёвых моделях, правила для `CLAUDE.md` и проверка, что экономия настоящая | Python 3.9+ |
| [`skills/topic-radar/`](skills/topic-radar/) | **Система поиска тем.** Держит карту написанного, ловит дубли, считает спрос и скорит кандидатов по 8 критериям. Внутри — как вывести свои веса по цифрам своего канала | — |
| [`skills/morning/`](skills/morning/) | **Утренний планировщик.** Собирает задачи из четырёх сфер, выбирает один фокус дня с обоснованием, пишет заметку и отправляет пост в Telegram | Python 3.9+, Obsidian, бот Telegram |

## Инструменты и разборы

Не скилы — отдельные скрипты и приёмы, которые можно взять по частям.

| Раздел | Что это | Что нужно |
|---|---|---|
| [`memory-system/`](memory-system/) | **Структура памяти для ИИ-агента.** Три отдела с разными правилами, условное чтение, шаблоны файлов. Разбор + шаблоны, кода нет | — |
| [`wordstat/`](wordstat/) | **Проверка спроса на темы** через Яндекс Вордстат: частотность, динамика, регионы. Источник цифр для `topic-radar` | Python 3.9+, токен Вордстата |
| [`covers/`](covers/) | **Кириллица на обложках:** как заставить нейросеть написать по-русски и не получить «ПОЛОВЙНА». Шаблон промпта + запасной путь через Pillow | — (для Pillow: Python 3.9+) |

## С чего начать

- **Платишь за агента и хочешь понять, за что** → [`skills/token-budget/`](skills/token-budget/).
  Самостоятельный продукт: ставится одной командой, работает без интернета и ключей.
- **Не знаешь, о чём писать дальше** → [`skills/topic-radar/`](skills/topic-radar/),
  потом [`wordstat/`](wordstat/) для цифр спроса.
- **Агент забывает тебя каждый новый чат** → [`memory-system/`](memory-system/).

## Про секреты

Ни одного токена и ключа в коде нет. Где они нужны, рядом лежит `.env.example` со
списком переменных — заполняешь своими, `.env` в гит не попадает.

Бери, ставь, ломай под свои задачи. Вопросы и разборы — в канале
[@ai_styledanila](https://t.me/ai_styledanila).
